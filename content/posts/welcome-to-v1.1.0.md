Finally! We are now on version 1.1.0. I made a lot of changes for this version of the website. The following changes were made: the hamburger menu was not working properly, implementation of a bottom-to-top scroller, added a search function, and the sidebar will disappear on smaller devices for a better reading experience.

I'm happy with the results, and I can start using my blog now for what it's made for.

## Contribute

This whole website/blog was made in Hugo, a framework for static websites. The theme that I made, which you are seeing now, is completely free and open source. Meaning that everybody is able to participate, download, change, and modify it. You can even make changes to this theme if you want. Making a push commit on this project will make me happy. I love the FOSS community!

So if you'd like to implement something or if you see any misspellings, you can commit those changes. We use GitHub for that, and the source is here: <a href="https://github.com/ramackersjp/404BrainNotFound" target="_blank">source</a>.
